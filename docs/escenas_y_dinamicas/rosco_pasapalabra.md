## 2. Banco extendido para funciones con improvisación

* **F - Fandom:** Conjunto de aficionados a algún pasatiempo, persona o fenómeno cultural.
* **G - Ghosting:** Cortar toda comunicación de forma repentina y sin explicación.
* **H - Hype:** Expectativa excesiva y euforia previa a un acontecimiento.
* **S - Shipeo:** Emparejar o desear el romance ficticio entre dos personas.
* **T - Troll:** Usuario que publica comentarios provocadores o irrelevantes con el fin de generar conflicto.
* **Z - Zillennial:** Microgeneración nacida en la transición entre Millennials y Generación Z.
